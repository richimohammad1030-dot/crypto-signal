## 2. Ide #36 · Saran lot otomatis (permintaan pemilik)
Skrip: `riset/xau/eksperimen/ide36_lot.py` (berisi juga fungsi usulan `saran_lot`).
Rumus: 1 lot XAU = 100 oz, jadi rugi di SL per 0,01 lot = jarak SL (USD) + biaya 0,40.
`lot_ideal = modal × 0,5% / ((jarak_SL + 0,40) × 100)`, dibulatkan **ke bawah** ke 0,01. Jika hasilnya < 0,01 → peringatan.

2026 saja lebih berat (ATR emas lebih besar): modal 10.000 → 57% sinyal kena peringatan, 20.000 → 11%.
Bacaan: **modal kecil + lot minimum = risiko jauh di atas 0,5%** (1.000 USD → rata-rata ±4%/trade, sekali-sekali 10-34%;
DD backtest 43% walau periode ini sangat untung). Hasil "terima" yang tinggi di modal kecil semata karena Feb 2025-skrg periode
bagus; dengan DD 43% itu bukan hasil yang aman untuk diandalkan. Melewati sinyal juga merusak edge (MR = trade paling sering
dilewati karena SL-nya terlebar). SL tetap 3 ATR sesuai keputusan pemilik.

### Rancangan
1. **Variabel** (GitHub Actions secret/variable, opsional; kosong = perilaku bot sekarang, tanpa saran lot):
   - `XAU_MODAL_USD` — modal akun (USD). Diperbarui pemilik sendiri bila saldo berubah banyak.
   - `XAU_RISK_MAX_PCT` (opsional, default = `XAU_RISK_PCT`) — batas risiko yang masih diterima pemilik bila lot minimum terpaksa dipakai.
   - `XAU_OZ_PER_LOT` (opsional, default 100) — ukuran kontrak broker (beberapa akun cent/mikro berbeda).
2. **Kapan:** setiap sinyal order baru (MR, K6, susulan), satu pesan tambahan ke **chat pribadi pemilik** (bukan channel), dikirim
   setelah bubble sinyal. K6 memakai jarak |entry - SL| order stop; MR/SUS memakai `dist`.
3. **Perhitungan:** fungsi `saran_lot` di `ide36_lot.py` (biaya 0,40 USD ikut dihitung; bulatkan ke bawah ke 0,01).
4. **Tiga keadaan pesan:**
   - lot ≥ 0,01 → saran lot + risiko USD & %.
   - lot < 0,01 tetapi risiko 0,01 lot ≤ `XAU_RISK_MAX_PCT` → saran 0,01 + catatan risiko sedikit di atas target.
   - risiko 0,01 lot > `XAU_RISK_MAX_PCT` → **PERINGATAN**: pilihan lewati / terima risiko X% (pemilik yang memutuskan).
5. Tidak mengubah strategi, catatan R, jurnal, kesehatan, maupun replay (pesan saja) → `replay_xau.py` tetap IDENTIK.

### Contoh pesan (chat pribadi)
Modal 15.000 USD, MR BUY, jarak SL 56,0 USD:
```
⚖️ <b>SARAN LOT XAU</b> · MR BUY
<pre>
Modal        : 15.000 USD
Risiko 0,5%  : 75 USD
Jarak SL     : 56,00 USD (+0,40 biaya)
Lot saran    : 0,01
Risiko nyata : 56 USD = 0,38% modal
</pre>
Lot dibulatkan ke bawah (kelipatan 0,01).
```
Modal 1.500 USD, jarak SL 56,0 USD:
```
⚠️ <b>LOT MINIMUM MELEBIHI RISIKO</b> · MR BUY
<pre>
Modal        : 1.500 USD
Risiko 0,5%  : 7,50 USD
Jarak SL     : 56,00 USD (+0,40 biaya)
Lot minimum  : 0,01 = 56 USD = 3,8% modal
</pre>
Pilihan Anda:
1) Lewati sinyal ini, atau
2) Terima risiko 3,8% (7,5x target 0,5%).
Untuk 0,01 lot ≤ 0,5% dengan SL ini dibutuhkan modal ±11.300 USD.
```

### Usulan perubahan bot (BELUM dipasang; menunggu persetujuan pemilik)
- `gold_templates.py`: fungsi baru `lot_bubble(pend, modal, risk_pct, risk_max_pct, oz_per_lot)` yang memakai rumus di atas dan
  mengembalikan teks salah satu dari tiga keadaan.
- `gold_bot.py` (`main`): baca `XAU_MODAL_USD`, `XAU_RISK_MAX_PCT`, `XAU_OZ_PER_LOT`; bila modal terisi dan `ev["order"]` ada →
  `tg_send(gt.lot_bubble(...))` tanpa `chat=target` (chat pribadi), setelah bubble sinyal.
- `.github/workflows/gold.yml`: teruskan ketiga variabel ke langkah bot (env).
- Opsional tahap 2: perintah `/modal 15000` di `commands.py` agar modal bisa diubah dari chat tanpa membuka GitHub.
- Uji sebelum pasang: `replay_xau.py` IDENTIK (pesan tambahan tidak mengubah mesin) + contoh pesan dengan modal 1.500 / 15.000.
